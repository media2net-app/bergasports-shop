Wat code-matig wél klaarstaat

  • Mollie create payment + webhook + return-pagina
  • Checkout: land, verzendopties, coupon, legal checkbox, Apple Pay-knop
  • Producttemplates: small / medium / premium
  • Host-based locale + NL|EN switch (domeinen .nl/.com nog te koppelen)

Mollie Payment API is aanwezig; de methodes-lijst hangt af van Dashboard-activatie (iDEAL, Apple Pay, cards, Bancontact) en correcte live key/profile op Vercel.
